# ⚙️ Embedded Firmware Practice

> A hands-on journey from C++ fundamentals to real-world embedded firmware development.

This repository documents my practical learning journey in **C++ and embedded systems**, with a focus on **Arduino, ESP32, microcontrollers, peripherals, communication protocols, and firmware architecture**.

The goal is simple:

**Learn → Build → Test → Debug → Improve**

Rather than learning embedded programming purely through theory, each concept is introduced through small, working firmware exercises and progressively more realistic systems.
